# Ox Wood 14U - Ozella: opponent scouting reports

Weekend opponent scouting reports built from GameChanger box scores and play-by-play text. `index.html` lists the reports newest first; each report is in `reports/YYYY-MM-DD.html`.

Every page is self-contained HTML (inline CSS/SVG, no JavaScript, no external assets).

Live site: https://joshualjordan79-collab.github.io/ox-wood-scouting/
